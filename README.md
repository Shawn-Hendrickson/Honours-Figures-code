# Honours-Figures-code
Code used for final plots of honours thesis

ARPES folder corresponds to figures in chapter 5, QTM corresponds to figures in chapter 6, Other refers to figures elsewhere.

## ARPES Folder

ARPES_intensity_density_plot.nb was used for Fig 4.1\
ARPES_symmetry_decomp_against_phi.nb was used for Fig 4.2, 4.3 & A.2\
D-vector_Chern_density_plot.nb was used for Fig 4.4

## QTM Folder

Hexagonal_Decomp is a helper file used for all QTM decomposition\
Momentum-transfer vectors graphic.nb was used for Fig 5.1\
QTM plot against R.nb was used for Fig 3.2 & 5.2\
QTM unperturbed equation r.nb was used for Fig 5.3\
QTM_vp+strain_ equation decomp with spectral functions Temperature.nb was used for Fig 5.4

## Other Folder

Graphene conde plot.nb was used for Fig 2.1\
gap_magnitude_example.ipynb was used for Fig 2.3\
symmetry decomp example.nb was used for Fig 3.1\
